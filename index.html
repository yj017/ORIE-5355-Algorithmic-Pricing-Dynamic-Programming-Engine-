Operations Research & Information Engineering

Algorithmic Pricing & Dynamic Programming Engine

1. Executive Summary

This project focuses on demand estimation and real-time revenue optimization in both monopoly and competitive environments. To meet a strict 0.5-second runtime limit, we decoupled the heavy computation into an offline Dynamic Programming solver and an online fast-lookup agent. By utilizing XGBoost for demand prediction and K-Means for state discretization, we achieved O(1) online pricing decisions.

2. Demand Estimation & Supervised Learning

We treated demand estimation as a supervised binary classification problem to predict the purchase probability P(Buy | Price, Features). We conducted a "Bake-Off" strategy evaluating three candidate models over a 500-timestep simulation:

Model Simulation Profit Inference Time Conclusion
Logistic Regression $15,265 19.8s Rejected. Failed to capture complex customer segments, leaving over $6,000 in potential revenue uncaptured.
Random Forest $20,142 15m 3s Rejected. While highly accurate, the massive overhead of querying hundreds of trees caused an unacceptable runtime bottleneck.
XGBoost (Champion) $21,236 21.8s Selected. Generated the highest profit while remaining 41x faster than Random Forest, successfully capturing non-linearities.

To generate the unconstrained optimal pricing CSV, we executed a vectorized grid search. The search grid utilized 200 points, concentrating 80% of the density in the $0 to $80 "Sweet Spot" region (where 75% of sales occur), and the remaining 20% in the sparse long-tail region.

3. Overcoming the Capacity Constraint (Offline DP)

Moving from unconstrained to constrained optimization introduced a severe complexity challenge. We face a finite inventory (Max = 20) that replenishes every cycle (T = 20). Every sale represents an opportunity cost—selling a unit now means it cannot be sold to a potentially higher-value customer later.

Because evaluating the optimal opportunity cost via the Bellman Equation is too slow for the 0.5-second real-time limit, we decoupled the process. We built an offline Dynamic Programming solver to pre-compute the optimal policy table.

State Discretization & The Bellman Equation

To make the state-space computationally tractable, we first clustered the infinite customer covariate space into K=20 discrete types using K-Means. Then, we solved the backward induction for the Value Function, V(t, i, k), representing time, inventory, and customer type:

V(t, i, k) = Max_p { P_buy * [ Price + V(t-1, i-1, k) ] + (1 - P_buy) * V(t-1, i, k) }

By doing this heavy lifting offline (which took ~33 seconds), the live Dynamic Agent only needs to perform an O(1) matrix lookup directly accessing the pre-computed optimal price.

4. Competitive Strategy & Adaptive Layer

In Part 2 (competition), we used our monopoly DP solution as a logical anchor. Rather than making fragile assumptions about opponent rationality, we implemented an adaptive feedback loop relying on observed behavioral signals—specifically our recent win rate and inventory depletion.

Dual-Prediction Bidding System

The dynamic agent maintains two competing models to anticipate opponent behavior:

  • Smart Prediction: Scales the baseline monopoly price by calculating a rolling 40th percentile of historical competitor-to-monopoly price ratios.
  • Dumb Prediction: Directly adjusts based on the last transaction—increasing by 10% if the opponent won, decreasing by 10% if we won.

The agent tracks an exponentially weighted moving average error to dynamically shift trust to the model with the lowest recent error margin. Finally, strict inventory floors are applied: holding firm at 90% of monopoly value for the final unit, or dropping to an aggressive $5 floor to liquidate excess stock.

5. Conclusion

The static pricing agent achieved 10th place out of 36 teams, validating our XGBoost and hybrid grid-search methodology. While the dynamic agent secured 17th place, we successfully engineered an architecture capable of O(1) decision-making under strict computational limits, providing valuable lessons in bridging high-fidelity offline models with latency-sensitive online execution.
